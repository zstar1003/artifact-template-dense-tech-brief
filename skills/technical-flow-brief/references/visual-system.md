# 紧凑红灰技术汇报

默认遵循已认可的克制配色，不因新增模块而增加新颜色。用户提供新方向时按用户要求调整。

## 配色

| 角色 | 色值 |
|---|---|
| 画布 / 表格 | `#FAFAF7` / `#FFFFFF` |
| 正文 / 次要文字 | `#171717` / `#5B5E59` |
| 标题 / 小范围重点字 | `#931C25` |
| 阶段条 / 表头 | `#ECEEEB` |
| 重点节点 / 必要结论带 | `#F1E8AA` |
| 边框 / 浅分隔 | `#9B9F97` / `#DCDFD8` |

不默认使用蓝、青、绿轮流给各层染色。层次靠位置、边界和标签表达；黑白打印仍须可理解。保留方角、细线，通常不加阴影、渐变、胶囊、大编号或图标。

## 几何参考

函数与作用相邻；英文长名优先加宽列或在驼峰/命名空间边界换行，不能改写符号。字体沿用现有参考；没有参考时选已安装的中文无衬线字体，换字体后重新验证。

## 高密度的取舍

先去重复句、装饰和无用框高，再收同组间距与内边距。不要把两行字悬在大卡片中央，也不要为了填满底部而把每行均匀拉高。

图中的留白需承担路由、对照或归属，允许空泳道；不能套用清单的 2 px 间距去挤连线。最终仍拥挤时拆成总览与局部展开，而不是所有页一律更小字号。

信息密度来自“对象 + 动作 + 条件 + 产物 + 关系”，不是单位面积的函数名数量。不要把所有 API 强放一页，也不要自动加占据三分之一宽度的解说侧栏。

## 原生对象与备注

图形、文字、箭头和表格保持可编辑。表格需要精确列宽及行高；固定行高时使用明确的段落行距与上下内边距，并检查最终导出的换行。不要靠隐藏溢出或截图遮盖问题。

主图关系不清时先修图，备注不能补救看不懂的连线。关键条件在正文，长解释及引用在备注。
