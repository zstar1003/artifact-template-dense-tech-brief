# 交付前检查

## 内容

- 范围明确：版本、模式、后端、入口、资源前提；不把一个子模式称为全部能力。
- 总览可沿主线读到完成，细节沿同一名称展开；没有用序号掩盖断掉的关系。
- 每个 API 有中文动作与对象；获取、创建、交换、传输、等待不混为一谈。
- 导出 API、内部方法、运行时与 C++ 操作归属明确。
- 调用路径有来源，定义或声明未冒充执行证据；静态/实测分开。
- 关键条件、资源复用及版本兼容在正文；不能只在备注纠正图的误导。

## 矩阵

- 比较轴解释真实差异，而不是重复几列相同算子。
- 全部共用行在前，部分共用、专用、特殊及待核各有位置；不重复计数。
- `✓`、`—`、待核的口径清楚；没有 `✓冷` 等复合符号。
- 条件列说什么时候调用，测试列说验证什么，不只是统计函数次数。
- 不同后端的数据执行者未被强行写成同一套 API。
- 共用接口结论不替代不同输入/算子的端到端结果验证。

## 视觉与可编辑性

- 最终导出的每页已渲染；修改页逐页看，未修改页与原版比对。
- 长函数完整，无裁切、极小字、页码碰撞；条件列不被压缩成脚注。
- 主线方向稳定；箭头不穿字，落点明确，局部分支不绕全页。
- 间距与文字行数相称；空白有路由/分组用途，不是卡片模板残留。
- 红灰淡黄含义稳定，不因模块多就增添多种饱和色。
- 原生图形与表格可编辑；照片/截图没有替代整页内容。
- 备注包含详细释义和本页证据，不包含内部生成日志。

## 发布

- 参考照片及原照片裁切没有进入技能、报告媒体、Git 暂存或公共预览。
- 新增包只含通用规则、代码和明确虚构的示例，不把业务报告默认打包。
- 公开文件没有机器绝对路径、用户数据、访问凭证或服务 Token。
- 推送仓库、分支和文件清单明确；不 force push、不改无关文件。
- 只报告实际完成的验证；渲染检查不称为 PowerPoint 实测，静态源码不称为上板验证。
